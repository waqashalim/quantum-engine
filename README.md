# QuantumCollider AI Learning Engine

Working React/Vite MVP for the AI-native pedagogical engine poster/demo.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Upload this folder to GitHub, or open it locally.
2. Run:
   ```bash
   npm install -g vercel
   vercel
   ```
3. Use the generated public URL for your poster QR code.

Poster QR label suggestion: **Scan to try the working MVP demo**
